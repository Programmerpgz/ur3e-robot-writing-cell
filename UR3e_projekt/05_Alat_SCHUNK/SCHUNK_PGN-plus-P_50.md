# Alat: SCHUNK PGN-plus-P 50-1 (pneumatska paralelna hvataljka)

| Parametar | Vrijednost |
| --- | --- |
| Hod po celjusti | 4 mm (ukupno 8 mm) |
| Sila zatvaranja / otvaranja | 220 N / 235 N |
| Radni tlak | 2,5 - 8 bar (nazivno 6) |
| Vrijeme otvaranja/zatvaranja | 0,015 s |
| Masa | 0,21 kg |
| Preporucena masa predmeta | 1,1 kg |
| Ponovljivost | 0,01 mm |
| Zastita | IP64 |

Provjera sile (marker, masa < 0,05 kg): F = S*m*(g+a)/mu = 2*0,05*(9,81+2)/0,3 = oko 3,9 N << 220 N. Dovoljno.
Ukupna masa na prirubnici (hvataljka 0,21 kg + marker) puno je ispod nosivosti UR3e od 3 kg.
U simulaciji prsti drze marker promjera 8 mm: raspon otvoreno 16 mm, stisnuto 8 mm (hod 4 mm po prstu). Alat: TCP je 140 mm od prirubnice.
